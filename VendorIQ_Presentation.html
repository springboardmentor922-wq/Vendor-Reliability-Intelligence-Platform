Engineering Resilience

Technical Challenges & Solutions

Obstacles encountered during development and how they were systematically resolved.

Challenge 1: Cold Start Supplier Data

Sparse Historical Metrics

Problem: Newly registered vendors had zero completed orders, skewing the reliability formula.
Solution: Developed Bayesian baseline defaults weighted by ISO certifications and compliance filings until order history matures.

Challenge 2: Complex State Synchronization

Multi-Role Order State Integrity

Problem: Concurrent updates could cause illegal transitions (e.g. delivered orders reverting to pending).
Solution: Created a strict backend finite state machine (FSM) enforcing valid status transitions across all procurement routes.

Challenge 3: Low-Latency Inference

Predictive Execution Speed

Problem: Running ML inference on high-volume procurement dashboard requests risked blocking API throughput.
Solution: Serialized pre-computed models with Joblib and implemented lightweight feature caching for sub-50ms query times.

Challenge 4: Professional UI Standards

Clean Visual System

Problem: Maintaining enterprise-grade look and feel without third-party chart libraries bloat.
Solution: Built custom pure SVG telemetry graphs, responsive glassmorphism containers, and typography inspired by modern enterprise design.
