User Flows

12 flows · decision points in red outline
Legend Stepprocess step Decision?decision point Endterminal state →flow direction
01

User registration flow

Angular form → FastAPI /auth/register → email verification
Open registration→ Enter name, email, password→ Select role→ Validation passed? NO →Show field errors YES →Create user (hashed password) → Send verification email→ Account pending admin approval
02

Login flow

Credentials → token issue → role-based dashboard
Enter email & password→ Credentials valid? NO →Error + attempt counter→Lock after 5 tries YES →Account approved?→Issue JWT + refresh token → Load role permissions→ Admin / Procurement dashboard
03

JWT authentication flow

Interceptor → token check → refresh or re-login
Angular HTTP request→ Interceptor attaches bearer token→ Token valid? YES →FastAPI dependency resolves user + role→200 response EXPIRED →POST /auth/refresh→Refresh valid?→Retry or 401 → login
04

Vendor registration flow

Procurement officer submits vendor for onboarding
Add vendor form→ Company + contact details→ Upload compliance documents→ Documents complete? NO →Saved as draft YES →Submit for approval→Status: Pending
05

Vendor approval flow

Compliance check → risk assignment → activation
Pending vendor in queue→ Automated compliance check→ Credit check cleared? NO →Request changes / reject→Notify requester YES →Assign risk level→Approve→Status: Active · selectable on PRs
06

Procurement request flow

Raise → budget check → approval → PO
Create request→ Select vendor by reliability→ Budget available? NO →Blocked — request budget transfer YES →Value > €50,000?→Finance co-sign → Approver decision→ Approved → raise PO
07

Purchase order flow

Issue → acknowledge → receipt → invoice match
Approved request→ Create PO (lines, dates, terms)→ Issue to vendor (email + portal)→ Acknowledged in 24h? NO →Reminder + score penalty YES →Goods receipt + inspection→Three-way invoice match → Completed
08

Delivery tracking flow

Milestones → delay detection → escalation
Vendor updates milestone→ Nightly job compares expected date→ Past expected date? NO →Status: on plan YES →Flag delayed + notify buyer & vendor→> 5 days late?→Escalate + record score impact
09

Vendor performance flow

Event capture → weighted scoring → risk level
Delivery, quality & issue events→ Celery job aggregates per vendor→ Apply weights 40/25/15/10/10→ Score < 70? NO →Update score & ranking YES →Raise risk level + alert→Performance review required
10

Contract renewal flow

Expiry alert → performance review → decision
90-day expiry alert→ Owner opens renewal review→ Reliability ≥ 70? YES →Renew as-is / negotiate terms→Signed → new term active NO →Renew with conditions or re-tender→Do not renew → archive
11

Notification flow

Event → rules → channel fan-out → read state
System event raised→ Rule engine assigns type & priority→ Priority high? YES →In-app + email + SMS NO →In-app only, batched digest → User opens notification→ Marked read · action logged
12

Report generation flow

Filters → async job → PDF / Excel → distribution
Choose template & filters→ Scheduled or on demand? ON DEMAND →Queue Celery job SCHEDULED →Cron trigger (Celery beat) → Query PostgreSQL + render→ Store file (24-month retention)→ Download or email to group
